# Contributing

Create a branch named `dev<N>/<feature>` or `feature/<name>`. Keep commits small and focused. Open pull requests against `develop`, include the API/model contract changes, and verify the backend health endpoint before requesting review.

Do not edit another module's private implementation. Coordinate through the shared schemas, API contracts, and model contract. If a cross-module change is required, make it a separate pull request and explain the dependency.
